# Калькулятор камер и вычислителя для видеоаналитики

[English](README.md) · **Русский**

Быстрая прикидка оборудования перед проектом: какие камеры и объективы поставить, увидит ли модель объект и сколько GPU для этого нужно.

**Открыть:** [sergeykrasnoslobodtsev.github.io/camera-calc](https://sergeykrasnoslobodtsev.github.io/camera-calc/) (интерфейс на английском и русском)

![Скриншот калькулятора](docs/view.png)

## Зачем

Проект видеоаналитики обычно начинается с требований: что детектировать, в какой зоне, с какого расстояния. Под них надо подобрать камеры, объективы и сервер, причём сразу, хотя ни стенда, ни замеров ещё нет.

Калькулятор нужен для быстрого ориентировочного расчёта. Он считает по формулам и паспортным данным, поэтому точной оценки не даёт: на вашем железе и ваших видео цифры могут отличаться.

## Что считает

- **Объект на входе модели.** Сколько пикселей получит объект после масштабирования к входу детектора, например 640 px, в одном из трёх режимов подачи: весь кадр, вырез зоны или тайлы. Результат калькулятор сравнивает с порогом минимального размера объекта.
- **Камера и объектив.** Высота и наклон камеры, зона наблюдения, фокусное расстояние, угол обзора. Плотность пикселей поперёк и вглубь кадра, уровни DORI по IEC 62676-4 и выдержка, при которой движущийся объект не смазывается.
- **Сеть.** Битрейт потоков H.264 и H.265, мощность PoE.
- **Вычислитель.** Нагрузка на инференс, декодер NVDEC и видеопамять. Из отмеченных GPU калькулятор подбирает самую дешёвую конфигурацию от 1 до 4 карт с заданным запасом.
- **Отчёт.** Итог текстом, чтобы вставить в письмо или ТЗ.

## Откуда цифры

- **Модели.** YOLO26 и YOLO11, детекция и pose. GFLOPs и задержка взяты из опубликованных замеров Ultralytics: T4, TensorRT FP16, batch 1, вход 640.
- **GPU.** Характеристики из даташитов NVIDIA: FP16 Tensor TFLOPS, число NVDEC, память, TDP. Производительность декодера — по NVIDIA Video Codec SDK 13.
- **Пересчёт на другую карту** идёт пропорционально FP16 TFLOPS относительно T4, с поправочным коэффициентом. Это приближение: реальная скорость зависит от архитектуры, драйвера, размера батча и всего пайплайна.
- **Цены** — ориентир на октябрь 2026, их можно изменить.

Если нужной карты или модели нет в каталоге, добавьте её на странице «Шаблоны»: свою GPU, камеру или детектор со своим замером скорости.

## Допущения

- Объектив считается идеальным прямолинейным (камера-обскура), а пол — ровной горизонтальной плоскостью. Дисторсию широкоугольных объективов калькулятор не моделирует, её учитывают вручную коэффициентом качества k.
- Все формулы есть на странице, в блоке «Все формулы».

## Данные

Всё считается в браузере, данные никуда не отправляются. Шаблоны и цены хранятся в `localStorage`, на другой компьютер их переносят экспортом и импортом JSON. Страница собирается в один HTML-файл, который открывается без сервера.

## Запуск

Нужен Node 26.

```bash
npm install
npm run dev     # сервер разработки
npm run build   # собрать dist/index.html
npm test        # проверка типов, линтер, тесты
```

Стек: TypeScript, React, Vite, Vitest и Testing Library, Oxlint. Внутренняя документация в `docs/` написана на русском.
