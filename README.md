# Калькулятор камер и вычислителя

Одностраничный инструмент для подбора камер, объективов и GPU под задачи видеоаналитики. Он считает геометрию кадра, плотность пикселей и сколько пикселей получит объект на входе модели. По нагрузке инференса, декодера и памяти он подбирает самую дешёвую конфигурацию видеокарт.

Готовая страница лежит в `dist/camera-calc.html`. Её можно открыть в браузере без сервера и сборки. Внешняя зависимость одна: шрифты IBM Plex с Google Fonts. Без сети страница покажет системные шрифты.

```
camera-calc/

├── tsconfig.json             настройки проверки типов tsc (build.ts, src/ и tests/)
├── dist/camera-calc.html     собранная страница (коммитится, чтобы открывать без сборки)
├── src/
│   ├── layout.html           разметка и CSS (тёмная тема, своя светлая по кнопке)
│   ├── formulas.html         текст блока «Все формулы»
│   ├── formulas.en.html      он же на английском
│   ├── main.ts               точка входа: подключает интерфейс к состоянию, загружает сохранение
│   ├── domain/               расчёт и сущности: справочники, разбор данных, расчёт типа камер и подбор GPU
│   ├── app/                  состояние, действия над ним, сохранение, импорт и экспорт
│   ├── i18n/                 словари RU и EN, t(), форматирование чисел, тексты результатов расчёта
│   └── ui/                   DOM: формы, результат, панель системы, шаблоны, схема, отчёт, подсказки
├── tests/
│   ├── domain/               юнит-тесты расчёта на node:test
│   ├── smoke.test.js         прогон в jsdom: отчёт, шаблоны, добавление камеры и детектора; ключи словарей
│   └── golden.test.js        тест-эталон: результаты расчёта сравниваются с golden.txt
└── docs/
    ├── architecture/         устройство модулей и принятые решения
    ├── ui-text-rules.md      правила текстов интерфейса и глоссарий RU ↔ EN
    └── design/               макеты раскладок (широкая и компактная), формат Claude Design
```

Модули связаны только через `import` и `export`. Порядок, в котором они выполняются при загрузке, задают импорты в `src/main.ts`. Карта модулей — в `docs/architecture/ARCHITECTURE.md`.

## Работа

```bash
npm install           # один раз, ставит esbuild, TypeScript, jsdom и Prettier
npm run build         # node build.ts; Node запускает .ts сам, проверено на Node 26.12
npm test              # проверка типов tsc, затем тесты
```

После правок в `src/` пересоберите страницу и закоммитьте `dist/` вместе с исходниками.

## Что считается

- **Геометрия.** Используется модель камеры-обскуры. Угол обзора: `HFOV = 2·atan(s / 2f)`. Фокусное в пикселях: `fpx = Nw / (2·tan(HFOV/2))`. Расстояние вдоль оптической оси: `z(x) = x·cos t + Hc·sin t`.
- **Плотность.** Поперёк кадра: `fpx / z`. Вглубь кадра: `fpx·sinφ / (D·cos²δ)`. Вертикальные габариты объекта берутся из точной проекции 8 углов его параллелепипеда.
- **Ориентация кадра.** Автоматически выбирается поворот, при котором `fpx` больше.
- **Объектив.** Если у камеры из шаблона задан диапазон фокусных, `f` ограничивается этим диапазоном, и геометрия пересчитывается.
- **Уровни DORI** по IEC 62676-4: 25 / 62 / 125 / 250 px/м.
- **Смаз.** Выдержка не должна превышать `blur / (v·ρ)`.
- **Битрейт.** `Nw·Nh·fps·bpp·сцена`, где bpp равен 0,04 для H.265 и 0,07 для H.264. PoE считается как 15,4 Вт на порт.
- **Вход модели** зависит от режима подачи:
  - весь кадр: масштаб `inp / max(Nu, Nv)`;
  - вырез зоны: масштаб `inp / max(roiW, roiH)`;
  - тайлы: масштаб 1, тайлы идут с шагом `inp·(1 − перекрытие)`.
- **Инференс.**
  - Модели из каталога: замер Ultralytics на T4 × `(640 / inp)²` × `FP16 карты / 65` × коэффициент реальности.
  - Свой детектор: замер × `(вход замера / inp)²` × `FP16 карты / FP16 карты замера`.
- **Декодер.** Число NVDEC умножается на производительность одного движка для поколения карты (Video Codec SDK 13).
- **Память.** 0,8 ГБ базово, плюс движки моделей, плюс 20 кадров NV12 на поток.
- **Подбор GPU.** Перебираются отмеченные карты в количестве от 1 до 4. Берётся самая дешёвая конфигурация, у которой загрузка не выше `1 / (1 + запас)`, а память занята не больше чем на 90% (у Jetson — не больше 60%).

Каталог GPU с характеристиками из даташитов NVIDIA: RTX 5090, RTX PRO 6000 Blackwell, L40S, H100 NVL, H200 NVL, Jetson AGX Orin 64GB. Цены, отметки «в подборе», свои карты, камеры и детекторы сохраняются в `localStorage` (ключ `camcalc3`). Чтобы перенести их на другой компьютер, на странице «Шаблоны» есть кнопки «Экспорт» (скачивает `camera-calc.json`) и «Импорт» (заменяет все данные содержимым файла).
