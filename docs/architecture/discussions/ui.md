## 2026-10-28 — нужен ли фреймворк интерфейса

**Статус:** не проверял

**Вопрос.** Интерфейс обновляется вручную: `innerHTML` и навешивание обработчиков заново после каждой отрисовки. Подключать ли фреймворк при переходе на новую структуру.

**Варианты.**

- Без фреймворка: файлы в `src/ui/` по экранам и блокам, отрисовка по состоянию из `app`. Нет зависимостей, способ отрисовки не меняется.
- Небольшой фреймворк (Preact, Lit, Svelte): обновление DOM по изменению состояния, обработчики не навешиваются вручную. Новая зависимость в коде страницы, новый синтаксис компонентов, переписывается вся отрисовка.

**Гипотеза.** Перестройку структуры и смену способа отрисовки лучше не совмещать: тест-эталон проверяет страницу целиком, и при двух изменениях сразу непонятно, какое из них сломало результат. Фреймворк, если понадобится, подключается после перехода, к готовым `domain` и `app`.

**Дальше.** Вернуться к вопросу после разделения `ui` по файлам: посчитать, сколько кода занимает ручное обновление DOM и навешивание обработчиков, и выбрать по правилу выбора инструментов из [`ARCHITECTURE.md`](../ARCHITECTURE.md#выбор-инструментов).
