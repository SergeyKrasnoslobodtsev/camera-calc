Hc = H − h is the camera height above the plane. x is the floor distance from the point below the camera (negative means behind it). The camera is tilted to the middle of the zone: t = (φ(x₁) + φ(x₂)) / 2.

HFOV = 2·arctan(s / 2f),  VFOV = 2·arctan(tan(HFOV/2) · Nh/Nw)
fpx = Nw / (2·tan(HFOV/2)) — focal length in pixels
φ(x) = arctan(Hc / x),  D = √(Hc² + x²),  δ = φ − t
z(x) = x·cos t + Hc·sin t — depth along the optical axis
frame width at line x: W = 2·z·tan(HFOV/2)
ρacross = fpx / z
ρdepth = fpx · sin φ / (D · cos²δ)
object, px = size · ρ · k
tmax = blur / (v · ρmax)
object box — projection of the 8 corners of a W × L × H box standing on the plane, at the worst point of the zone, × k
bitrate = Nw · Nh · fps · bpp · scene factor
scale to model input: full frame min(1, input / max(Nw, Nh)); crop min(1, input / max(ROI)); tiles 1
tiles = ⌈(ROIw − input) / step⌉ + 1 per axis, step = input · (1 − overlap)
model load = cameras · analytics fps · calls per frame · (tiles)
model capacity = fps on T4 · (640 / input)² · FP16GPU / 65 · kderating (or custom benchmark · FP16GPU / FP16benchmark GPU)
GPUs per model = load / capacity
decoding = cameras · Nw · Nh · fps / (1920 · 1080 · 30) / (NVDEC · fps per NVDEC / 30 · kderating)
GPU memory per GPU ≈ 0.8 GB + Σ models (0.15 GB + 16 · input² · 6 B · GFLOPs/4) + streams per GPU · 20 · Nw · Nh · 1.5 B
best price: minimum price n · GPU price for n = 1…4 where inference and decoder ≤ 1/(1 + headroom), memory ≤ 90% (Jetson 60%)

The model is an ideal rectilinear lens (pinhole camera) and a horizontal plane. The density formulas are checked against a numerical projection of pixels onto the plane. Account for the distortion of real wide-angle lenses with the quality factor k.

Several camera types: inference load is the sum over all inference runs of all types. One model with the same input size takes memory once. Decoding is the sum over types, accounting for their codec. Custom model: benchmark × (benchmark input / input)² × FP16 GPU / FP16 benchmark GPU.
