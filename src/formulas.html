Hc = H − h — высота камеры над плоскостью. x — расстояние по полу от точки под камерой (отрицательное — позади неё). Камера наклонена на середину зоны: t = (φ(x₁) + φ(x₂)) / 2.

HFOV = 2·arctg(s / 2f),  VFOV = 2·arctg(tg(HFOV/2) · Nh/Nw)
fpx = Nw / (2·tg(HFOV/2)) — фокусное в пикселях
φ(x) = arctg(Hc / x),  D = √(Hc² + x²),  δ = φ − t
z(x) = x·cos t + Hc·sin t — глубина по оптической оси
ширина кадра на линии x: W = 2·z·tg(HFOV/2)
ρпоперёк = fpx / z
ρвглубь = fpx · sin φ / (D · cos²δ)
объект, px = размер · ρ · k
tmax = смаз / (v · ρmax)
рамка объекта — проекция 8 углов параллелепипеда Ш × Д × В, стоящего на плоскости, в худшей точке зоны, × k
битрейт = Nw · Nh · fps · bpp · коэффициент сцены
масштаб на вход модели: весь кадр min(1, вход / max(Nw, Nh)); вырез min(1, вход / max(ROI)); тайлы 1
тайлов = ⌈(ROIw − вход) / шаг⌉ + 1 по каждой оси, шаг = вход · (1 − перекрытие)
нагрузка модели = камер · кадр/с аналитики · вызовов на кадр · (тайлов)
ёмкость модели = кадр/с на T4 · (640 / вход)² · FP16GPU / 65 · kреальн (или свой замер · FP16GPU / FP16GPU замера)
GPU на модель = нагрузка / ёмкость
декодирование = камер · Nw · Nh · fps / (1920 · 1080 · 30) / (NVDEC · кадр/с на NVDEC / 30 · kреальн)
видеопамять на GPU ≈ 0,8 ГБ + Σ моделей (0,15 ГБ + 16 · вход² · 6 Б · GFLOPs/4) + потоков на GPU · 20 · Nw · Nh · 1,5 Б
оптимум: минимальная цена n · цена GPU при n = 1…4, где инференс и декодер ≤ 1/(1 + запас), память ≤ 90% (Jetson 60%)

Модель — идеальный прямолинейный объектив (камера-обскура) и горизонтальная плоскость. Формулы плотности сверены с численной проекцией пикселей на плоскость. Дисторсию реальных широкоугольных объективов учитывайте через коэффициент k.

Несколько типов камер: нагрузка инференса — сумма по всем запускам всех типов. Одна модель с одинаковым входом занимает память один раз. Декодирование — сумма по типам с учётом их кодека. Свой детектор: замер × (вход замера / вход)² × FP16 GPU / FP16 GPU замера.
